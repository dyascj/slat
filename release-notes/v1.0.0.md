The first release of Slat, a scrolling tiling window manager for macOS written in Rust.

- Columns and Canvas layouts
- Virtual workspaces, trackpad swipes and scroll-wheel sliding
- App rules, Mac Setup check, and a guided onboarding with a shortcut trainer
- One-click signed updates from the menu bar

Download `Slat.zip`, move `Slat.app` to Applications, and right-click > Open the first time.
