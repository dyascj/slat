Steadier focus, safer settings, and a lot of small fixes.

- **Closing a window no longer moves your focus.** When a window you weren't using closed or minimized (a terminal whose command finished, a download window), Slat moved focus to another window in the row. Focus now stays where it is.
- **Settings can't be lost to a half-written file.** Settings are now saved in one step, so the menu bar and an open window can never read a partly written file and fall back to defaults. The Settings window also picks up changes made in onboarding or Mac Setup instead of saving over them.
- **A clear reason when tiling can't start.** If "Displays have separate Spaces" is off, or a hand-edited `engine.toml` has an error, the menu now says so. Slat no longer keeps restarting the engine with "status 0".
- **Removing a float rule keeps windows on their display.** Windows of an app you had set to float now tile back into the row on their own display, not the one you're looking at.
- **Deep stacks stay in place.** Stacking more windows than fit in a column used to leave them sitting under the next column. They now share the column evenly.
- **Deleting a macOS Space removes all of its workspace rows.** Rows from a deleted Space no longer linger or come back after a restart.
- **Sturdier with misbehaving apps.** Apps that report an odd window title, or a window that closes at just the wrong moment, can no longer crash the engine. Canvas windows saved on a taller display come back on screen.
- **Updates explain what's wrong.** If Slat is running from a quarantined copy that can't be updated in place, the updater asks you to move it to Applications first.
- **Smaller fixes.** The menu bar's workspace shortcuts show the right keys and hide when workspaces are off. "Open in Editor" opens your default text editor. Key combos follow the macOS order (⌥⌘). Balance ignores floating windows. The engine log starts fresh past 10 MB, and saved state is flushed to disk.
