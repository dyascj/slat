Smoother sliding, and settings that apply right away.

- Sliding the row across windows from different apps no longer stutters. Animation now steps once per display frame, each app's windows move on their own thread so a busy app can't hold up the rest, and focus changes no longer wait on the app being activated.
- Changes made in Settings take effect immediately. Before, the engine missed the way Slat saves its config and only picked changes up after a restart.
